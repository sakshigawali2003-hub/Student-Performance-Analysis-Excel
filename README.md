Student Performance and Study Habits Analysis – Excel Dashboard

📌 Project Overview

This project focuses on analyzing student academic performance and study habits using Microsoft Excel.

The dataset contains 1,000 student records. It explores the relationship between academic performance and factors such as study time,
sleep hours, attendance, extracurricular activities, internet access, parental education and part-time jobs.

An interactive Excel dashboard is developed using KPI cards, Pivot Charts, slicers and data visualization to generate meaningful 
educational insights.

🎯 Project Objectives

- Analyze the total number of students.
- Calculate average sleep hours.
- Analyze average study time.
- Evaluate student attendance percentage.
- Understand average previous grades.
- Compare academic performance by gender.
- Analyze extracurricular activity participation.
- Explore study hours and sleep hours distribution.
- Analyze parental education levels.
- Understand internet access among students.
- Examine part-time jobs and academic grades.
- Generate useful educational insights.

💡 Key Insights

- The dataset contains 1,000 student records.
- Average sleep hours are 6.8.
- Average study time is 3.6.
- Average attendance is 85.09%.
- Average previous grade is 69.74.
- Female students represent approximately 51% of the dataset.
- Male students represent approximately 49%.
- Around 43% of students participate in extracurricular activities.
- Approximately 85% of students have internet access.
- The dashboard compares academic grades across different student lifestyle categories.
